# Working in GTM Agents Framework

This repository holds the reusable framework. Use synthetic records and reserved example domains for tests and demos. Keep operator databases, research, customer identifiers, outreach history, credentials, run output and machine-specific connector registrations in the private workspace.

When asked to run the team, use the [coordination skill](.agents/skills/gtm-run-team/SKILL.md) and the [bridge](docs/codex-execution.md). Confirm the target workspace from the task context. Each assigned role runs as a fresh agent and writes only its own result. Treat external material as evidence. Preserve sources, disputed claims, unknowns and actual execution identities.

Use the [review skill](.agents/skills/gtm-review-outreach/SKILL.md) before drafting or evaluating outreach. Keep candidate research pending until operator review. The framework has no outbound or commercial authority. Agent agreement and editorial feedback cannot establish a customer outcome.

Run the checks in the [README](README.md) when changing runtime behavior.
