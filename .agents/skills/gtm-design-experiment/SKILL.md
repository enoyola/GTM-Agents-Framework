# Design a GTM experiment

Start with the decision the operator needs to make. Record the baseline, candidate, evidence, dissent and a plausible alternative explanation. When the audience and message would both change, choose the variable that distinguishes the competing hypotheses.

Use the [experiment template](../../../templates/experiment.md) to specify the assignment unit, eligibility, exposure, primary metric and denominator, maturation window, resource limits, stopping conditions and decision rule. Identify the person who can authorize enrollment. The local runtime saves proposals.

At review, account for pending outcomes, missing exposure and material deviations. Record an inconclusive result if the evidence cannot support a decision. Use the [playbook change record](../../../templates/playbook-change.md) for a scoped adoption or rollback, with the prior version and existing commitments preserved.
